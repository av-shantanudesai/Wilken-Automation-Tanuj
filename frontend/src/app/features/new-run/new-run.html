Dummy Wilken on this PC
  1. Start API, this dashboard, and the worker with dotnet run --project WilkenAutomation.Worker --no-launch-profile -- --desktop-test — not --replica-login-smoke (that CLI starts jobs immediately and skips this page).
  2. Leave the worker idle. Dummy Wilken must not open yet.
  3. Set Mandant here to the same value you will type in Anmeldung (replica default is 02). Keep Start immediately checked.
  4. Click Generate jobs. The worker claims the first job, then opens the dummy desktop.
  5. Complete EHP (Start Wilken) and Anmeldung (Anmelden). Automation starts at Prozesse verwalten after that.

Cancel any old running run first, or the worker may open Wilken before you click Generate.

Real Citrix test environment
  1. Enter the same Mandant on this page that you will type in Wilken Anmeldung (e.g. 02). Generate jobs. The dashboard does not log you in.
  2. On the Citrix Test Environment desktop, start Wilken TEST / Wilken VDI.
  3. Complete EHP (Country, Company, Start Wilken), any warning with OK, then Anmeldung (Benutzer, Passwort, Mandant, Anmelden).
  4. Wait until the main screen with Navigation is visible. The worker waits for that screen, then starts at Prozesse verwalten.
  5. The worker must run inside that same desktop — not on the PC that only has the browser.

The worker never types Wilken username, password, or Mandant into login. It does not click Start Wilken or Anmelden.
